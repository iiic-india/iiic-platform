Rules:

1. A source file is never edited to "improve" the text. Corrections go in the notes under it, with the reason.
2. A line used on the platform is traceable: `[IIIC]`, `[CS]` or `[proposal]` in the copy architecture, and the CMS stores the source reference for facts (the `facts` field on pages, M2).
3. Placeholders carry their input ID (`[[TODO: course dates, I-14]]`), so the placeholder report on `/admin` → Content → Placeholders reads as a to-do list for IIIC.
