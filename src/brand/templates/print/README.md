# Print templates

A4 documents and the business card, built on `css/05-print.css`. Each opens in a browser as a page preview and prints at true size. `pdf/` holds a **specimen** of each: the values describe the template itself, nothing is a real client, official, fee or record, and every page carries a SPECIMEN watermark.

The device: the logo's yellow bar runs down the left edge of every business page. Paper is white, type is ink, headings are Fraunces. Yellow appears as the bar, the total block, the proposal cover and the certificate seal, never on a dark ground.

## Two kinds of page

| Kind | Class | Behaviour |
| --- | --- | --- |
| Fixed sheet | `.iiic-sheet` | Exactly one page. The proposal cover and the certificate. |
| Flowing document | `.iiic-sheet.iiic-sheet-flow` | As long as its content. In print it paginates; the yellow bar, the footer and "Page n of N" repeat on every page through CSS page margin boxes, and the letterhead block appears on the first page only. Add `.is-confidential` for proposals and `.iiic-doc-compact` for invoices. |

Page margin boxes need Chromium 131 or later (the platform's PDF renderer). Firefox prints flowing documents without the repeated bar and footer.

## Templates

| File | Use | Notes |
| --- | --- | --- |
| `letterhead.html` | Letters generated by the platform | Reference, date, recipient block, `{{body_paragraphs}}`, signature block; registration line in the header. People writing letters by hand use `../office/IIIC-letterhead.docx`. |
| `invoice.html` | The brand reference for invoices (the platform issues them through Zoho Books) and the fallback for receipts | `{{document_type}}`: "Invoice" or "Receipt" with no GSTIN line and no tax rows while IIIC is not GST-registered; "Tax invoice", "Receipt voucher", "Refund voucher" or "Credit note" once registered (a CA confirms). `{{line_items}}` takes one `<tr>` per line (pattern in the file); CGST + SGST within Gujarat, IGST for other states; reverse charge line; authorised signatory block. |
| `proposal.html` | Consultancy proposals generated or exported by the platform | Yellow cover with the logo on a white base; a flowing, confidential body: situation, `{{phase_rows}}`, measures, `{{fee_rows}}` with a yellow total, next step, acceptance block. |
| `certificate.html` | Course certificates | Landscape; certificate ID, `{{certificate_statement}}` (fixed, lawyer-approved wording: never "degree", "diploma", "university", "accredited", "recognised" or "approved"), signatory, the seal, and `{{verify_qr_svg}}`: an SVG QR code of the verify URL, generated per certificate. |
| `business-card.html` | Visiting cards | India standard 89 × 51 mm trim, PDF page 95 × 57 mm with 3 mm bleed. Front: bar, name, role, contact. Back: the mark on the yellow field. Keep text inside the 4 mm safe zone. |

## Rendering PDFs

Playwright or Chrome headless: `page.pdf({ printBackground: true, preferCSSPageSize: true })`. Every `@page` rule in the kit is named (`iiic-sheet`, `landscape`, `iiic-flow`, `iiic-flow-confidential`, `card`) and every print adjustment is scoped to `.iiic-print-body`, so printing an ordinary web page keeps the browser's own margins and colour settings. The fonts are self-hosted, so the PDF embeds Fraunces and Manrope wherever it is rendered. Browser: File → Print → Save as PDF, margins Default, background graphics on.

## Rules

- Every `{{merge_field}}` is filled before a document is issued; none is guessed. GSTIN or registration status, Udyam number, bank details, programme details and the verify URL are the team's to supply.
- The full lockup goes on white. The proposal cover carries it on the white base, never on the yellow field.
- Body text 10.5pt Manrope, headings Fraunces; print on white stock.
- The letterhead's registration line should show the registration ERNET will see (Udyam or GST), with the same name and address as on that certificate.
- The seal is a mark of the institute, not a legal stamp. Certificates and formal letters only.
