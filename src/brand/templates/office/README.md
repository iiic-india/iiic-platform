# Office templates

Word templates for people who write letters and documents by hand. They open in Microsoft Word, Google Docs (File → Open, then upload) and LibreOffice. Fonts are Georgia for titles and Arial for text, so they look the same on every machine.

| File | Use |
| --- | --- |
| `IIIC-letterhead.docx` | Letters: ERNET, universities, clients, partners. The letterhead block is on page 1; the yellow bar and the footer with the page number repeat on every page. |
| `IIIC-document.docx` | Proposals, reports, briefs and notes. Title, subtitle and a details table on page 1; Heading 1 and Heading 2 styles (they feed the navigation pane and a table of contents); the IIIC table pattern; the IIIC bullet style; a confidential footer with page numbers. |

## How to use

1. Open the file, then Save As with a new name. Do not edit the template itself.
2. Replace every field in square brackets.
3. Use the built-in styles (Title, Subtitle, Heading 1, Heading 2, Kicker, Small, Normal) rather than formatting by hand.
4. Export to PDF for sending: File → Save As → PDF.

The yellow bar is a picture anchored to each page inside the header; if it moves, undo rather than dragging it back. The generated versions of letters and documents (with the same look) are the HTML templates in `../print/`.
